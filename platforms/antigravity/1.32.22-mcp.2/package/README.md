# CARBON Core for Antigravity

Jay, your AI test manager. Free and open source (MIT). This is a local candidate,
not an approved Marketplace listing. Node.js 22+ and Python 3.10+ are required.

## Install and start

From the directory containing the extracted package folder, run after native testing is authorized:

```sh
agy plugin validate --strict ./package
agy plugin install ./package
agy plugin list --json
```

Approve only the local CARBON stdio server you intend to use. Try /carbon, /jay,
/full or /carbon-demo. There are 13 skill entry points (12 commands plus /j alias)
and eight MCP tools. Use the host's tools to execute checks; CARBON records and
renders the evidence. Unavailable tools must be reported as blocked, not passed.

CARBON stores reports and preferences locally; the host model and tools have their own data policies. No account or CARBON API key,
automatic hooks, background execution or analytics. Model usage is supplied and
billed by your host. Core does not include Pro's proof command.

Read PRIVACY.md, SECURITY.md and REVIEWER-NOTES.md. Submit only after strict CLI
validation and an actual Antigravity run, through the partner intake linked from
https://antigravity.google/docs/build-plugins . No submission has been performed.

Eight tools are returned by tools/list: seven agent-facing tools plus carbon_status, marked app-only in MCP Apps metadata. Whether Antigravity honors that visibility or renders MCP Apps has not been verified. The protected browser report is the fallback.
