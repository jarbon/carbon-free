## Listing copy

CARBON Core brings Jay, your AI test manager, into your agent. Prioritize risky changes,
investigate bugs, exercise important user journeys, and keep reproducible findings,
screenshots and coverage gaps in local HTML reports. Includes accessibility checks,
disposable TestBucks demos, and the full testing campaign. Host tools and permissions
determine which checks can run; blocked checks remain visible.

13 command entry points including the j alias for jay; 12 distinct commands.
8 MCP tools. No claim that retrieving a workflow runs a test.
No Pro formal-proof command, model credits, hosted browser or cloud service included.

## Prerequisites and permissions

Node.js 22+ and Python 3.10+ for demo/full helpers. User-authorized browser and shell
tools come from the host. Local stdio MCP, no hosted endpoint or API key required.
Analytics is disabled in platform configuration; packaged skill invocation counters
are removed. No automatic hooks, unattended jobs, account changes or external sends.
The report server binds to loopback with capability protection. Reports can contain
source and screenshots: review before sharing. Do not forward capability tokens.
